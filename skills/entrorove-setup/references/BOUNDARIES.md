# 边界与故障处理

- 市场内容负责安装引导与使用说明；运行能力来自官方 npm。市场目录不含用户凭证、SDK 程序、依赖或机器路径。
- 本地任务由当前 IDE 或办公代理执行。云端分析和可选沙箱的结果是参考与证据，不为本地文件操作授予权限。
- 复用用户原始授权、账号凭证和已有任务，不为每一步重复创建任务、申请密钥或增加确认。真正的新范围、不可逆动作或平台要求的组织授权按实际条件处理。
- 本引导的安装命令显式使用 `--no-hooks`。需要可选监听或工具守卫时由用户另行选择；登记成功不证明宿主已加载，也不保证回调覆盖全部工具。
- `ide.sdkReady` 表示 SDK 入口可用；`ide.configured` 与 `ide.configuredScope` 描述 IDE 注入配置，不表示密钥有效或无效。凭证有效性由实际 SDK 请求确认。
- SDK 不可用时保留明确错误与未执行状态，继续已经授权且当前工具能够完成的工作。测试结论是验证证据，不成为普通开发工作的许可。
- 小步可逆改动合并到功能点或交付边界测试。不可逆点、共享核心变更和用户要求即时验证按既有规则处理；不为重复安装引导逐条启动全量回归。
- 不宣称所有软件、操作系统或 SaaS 沙箱均已实测。按产品分别记录文档契约、安装器检查、真实加载和能力执行。

[在线示例](https://demo.entrorove.com)可展示交付物。网站可访问或存在示例不能证明审核环境已执行 SDK，也不代替具体功能的测试记录。
